# Peruri Revanth - Portfolio Website

A clean, modern, responsive developer portfolio for **Peruri Revanth**, B.Tech Computer Science student at Parul University, Full Stack Developer, and AI/ML enthusiast.

## 🚀 Features

- **Modern & User-Friendly Design**: Inspired by the clean, elegant aesthetic of [tarunkomati.in](https://tarunkomati.in).
- **Dark & Light Mode**: Smooth theme toggling with persistent preferences.
- **Hero Showcase**: High-res portrait with gradient framing, status indicator, and dynamic headline.
- **Things I Love**: Core specializations in Full-Stack Web Development, AI & NLP, and System Security.
- **About Me**: Narrative bio, quick facts (Parul University, Vadodara, CGPA 6.67).
- **Skills Grid**: Filtered inventory of languages, frontend, backend, databases, and AI tools.
- **Featured Projects**:
  - **Bug Bounty Platform (2026)**: Next.js, Node.js, Express, PostgreSQL, Groq AI API, JWT, Cloudinary, RBAC.
  - **Hashtag Generator using AI & NLP (2026)**: React.js, Flask, NLP, Image Analysis, REST APIs.
- **Interactive Demos**: Built-in Groq AI vulnerability triage simulator and AI hashtag generator.
- **Education & Certifications**: Parul University B.Tech, Intermediate MPC, SSC, and verified certifications.
- **Interactive Contact**: One-click clipboard copy for email and phone, plus responsive contact form.
- **Printable Resume Modal**: Built-in modal with print / save to PDF functionality.

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+), Bootstrap Icons, Google Fonts (Rubik)
- **Backend / Server**: Node.js HTTP Server (`server.js`)

## 💻 Quick Start

### Run locally:
```bash
node server.js
```
Then open [http://localhost:3000](http://localhost:3000) in your browser.
